# Security Policy

Please do **not** report security vulnerabilities through public GitHub issues.

Report them privately via GitHub's "Report a vulnerability" function
(Security tab of this repository) or by email to security@rheininsights.com.

Please include a description of the issue, the steps to reproduce it, and the
affected version. We aim to acknowledge reports within 5 working days.

This project is a fork of the retired Microsoft Bot Framework SDK for Java.
Don't report vulnerabilities in this fork to Microsoft.
